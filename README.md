## 🌐 Overview

**Rayhan's Lab** is an interactive learning platform designed to make complex theoretical concepts intuitive through hands-on simulations, real-time calculators, canvas visualizers, and structured study notes.

Visit the live platform at **[rhrayhan.dev](https://rhrayhan.dev/)**.

---

## 🚀 Key Modules & Interactive Tools

### 💻 Computer Science
- **Dijkstra's Algorithm Visualizer**: Step-by-step shortest-path graph search simulator.
- **Graph Theory Suite**: Interactive graph sandbox, traversal animations, and adjacency matrix vs. adjacency list representations.
- **Modular Arithmetic & Cryptography**:
  - Chinese Remainder Theorem (CRT) interactive solver
  - Modular Inverse Calculator & Extended Euclidean algorithm
  - Congruence relations and number theory guides
- **Digital Logic & Circuit Simulation**: Interactive JK Flip-Flop and sequential counter simulator.
- **Numerical Methods**: Least Squares Curve Fitting interactive lecture notes.

### 🌌 Physics
- **3D & 2D Visual Simulations**: Built with Three.js and HTML5 Canvas (pendulum dynamics, projectile trajectory, wave mechanics).
- **Newtonian Mechanics**: Interactive forces, velocity, acceleration, and friction simulation.
- **Universal Gravitation**: Kepler's laws, gravitational field, escape velocity, and satellite orbital mechanics.
- **Vector Dynamics**: 2D & 3D vector operations, dot/cross products, and component resolution.
- **Physics First Paper Index**: Structured breakdown of mechanics, thermodynamics, waves, optics, and modern physics.

### 📐 Mathematics
- Foundational and advanced notes on Discrete Mathematics, Graph Theory, Number Theory, and Applied Calculus.

## 🛠️ Technology Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom design system, glassmorphism, responsive mobile-first layouts)
- **Logic & Scripting**: Vanilla JavaScript (ES6+)
- **Graphics & Simulation**: Three.js, HTML5 Canvas 2D API
- **Hosting & Deployment**: GitHub Pages with Custom Domain ([rhrayhan.dev](https://rhrayhan.dev/))
